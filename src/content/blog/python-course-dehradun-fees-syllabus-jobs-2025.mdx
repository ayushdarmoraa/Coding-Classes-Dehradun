# Python Course in Dehradun

Compare a course's published curriculum, duration, fees, prerequisites, and delivery availability before enrolling. This guide summarizes the current Python course record at Doon Coding Academy (DCA); confirm current batch information with the academy.

## Published curriculum

The scheduled Python course is 4 months. Its curriculum lists:

- Python basics and data types
- Control flow, functions, and modules
- Lists, dictionaries, and sets
- Object-oriented programming and error handling
- Files, JSON, and simple CLI projects

The published pricing lists a ₹12,000 package rate and a separate ₹4,000/month rate option.

The course record lists outcomes including writing Python scripts, understanding object-oriented programming and modules, and building small utilities. It does not list a data science, machine-learning, or AI curriculum; see the separate Data Science & AI course details for that curriculum and confirm its current availability.

## What to compare before enrolling

- Check that the curriculum matches the topics you want to study.
- Review the published prerequisites, duration, and outcomes.
- Confirm schedule, delivery format, and payment details directly with the provider.
- Ask whether any support or services you need are included. Do not assume recordings, mentoring, project feedback, internships, placement assistance, or employment outcomes.
